# Convention

* [Guides in docs, knowledge links to them](kit-docs.md) - The guides in docs/ are for people using the kit; the knowledge bundle links to them, and docs/commands.md is generated from the CLI's help.
* [Test fixtures and spec traceability](test-fixtures.md) - How CLI tests use one valid fixture with a single mutation per test, pinned vendored samples, and spec scenario references.
* [The kit follows the shipped code-comment convention](code-comments.md) - The kit's own code follows the code-comment convention it ships in template/; points to the shipped concept.
* [TypeScript style](typescript-style.md) - How the kit writes TypeScript for the CLI: strict compiler flags, Biome, small pure modules and errors as values.
