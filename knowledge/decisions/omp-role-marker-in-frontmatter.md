# Decision

Rejected: marking a role file that `agents sync` generated with an extra frontmatter key, such as `generated-by: specfold`.

The generated files start their body with `<!-- generated by specfold agents sync from .claude/agents/<name>.md; edit that file -->` instead. That line marks them as the sync's own and tells a reader where to edit.

# Why

omp's docs don't say what its agent parser does with unknown frontmatter keys. A key it rejects would make omp skip the role without notice. The body comment costs a few tokens of system prompt and is safe in any parser.
