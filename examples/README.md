# Examples

`sample-app/`: a worked example with one archived change, set up from `template/`. See its README.

`migrations/`: two recorded `sf-migrate` runs on the migration fixtures, each with the approved plan, the report and a README of the steps and checks.

`runs/pattern-2/`: a recorded M8 run of pattern 2 on the sample app: three implementer subagents in parallel worktrees, a split proposal, the verifier's findings and what the run found in the kit.
