# Specfold template payload

Everything in this folder is what a user repo receives: through "Use this template", `BOOTSTRAP.md` or `sf-migrate`. It is filled milestone by milestone (see `docs/plan.md` in the kit repo). So far it holds `specfold.yaml`, an OKF bundle with the code-comment convention, and the `specfold` OpenSpec schema with its config.

Never put the kit's own knowledge, specs or settings here.
